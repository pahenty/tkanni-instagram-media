# TKANNI Instagram Media

Публичное техническое хранилище финальных изображений, которые Instagram API
забирает перед публикацией постов магазина
[`tkanni.kz`](https://tkanni.kz).

## Что здесь хранится

- только финальные оптимизированные JPEG;
- размер кадра `1080×1350`, соотношение сторон `4:5`;
- цветовое пространство sRGB;
- отдельная папка на каждый опубликованный или подготовленный package.

## Чего здесь нет

- оригинальных фотографий товаров;
- XML-фида и внутренних снимков карточек;
- промптов, черновиков, журналов и редакционных отчётов;
- токенов Instagram, GitHub или других секретов.

Структура файлов:

```text
media/YYYY/MM/DD/PACKAGE_ID/01-cover.jpg
media/YYYY/MM/DD/PACKAGE_ID/02-slide.jpg
```

Ссылки для Instagram формируются через `raw.githubusercontent.com` с SHA
конкретного коммита. Поэтому проверенный файл не меняется между preflight и
загрузкой на стороне Meta.

## Хранение

Финальные изображения остаются в репозитории после публикации. Обычное
удаление файла не очищает историю Git и почти не экономит место, поэтому
репозиторий используется как воспроизводимый публичный архив. При приближении
репозитория к `1 GB` медиа переносятся в объектное хранилище с lifecycle
policy, а не удаляются переписыванием истории.
